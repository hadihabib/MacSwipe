# MacSwipe v0.4 — Android + Mac LAN trackpad

A Java-only Android application + Swift macOS receiver, built by GitHub Actions (no Android Studio / Kotlin plugin).

Features: cursor, clicks, two-finger scrolling, press-and-drag, three-finger desktop swipes and Mission Control, customizable quick command buttons in the source.

See [GITHUB-START-AR.md](GITHUB-START-AR.md) for Arabic upload and build instructions.

**Build status:** Not yet verified by a real GitHub Actions run. Uses Android Gradle Plugin 8.7.3 + Gradle 8.9 + JDK 17.
